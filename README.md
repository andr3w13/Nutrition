# Предсказание калорийности блюд

Мультимодальная нейросеть, которая оценивает калорийность блюда по фотографии, списку ингредиентов и массе порции. Модель считается готовой к интеграции в продукт при MAE < 50 ккал на тестовой выборке.

## Результаты

| Метрика | Значение |
| ---------------------------------------- | ----------------------------------------- |
| **MAE на test** | **35.23 ккал** |
| Лучший MAE на валидации | 28.70 ккал (27-я эпоха из 30) |

Целевой показатель MAE < 50 достигнут.

## Данные

3262 блюда (2755 train и 507 test), для каждого блюда есть фото сверху (640x480), список ингредиентов, масса порции и калорийность. Датасет скачивается с Google Drive первой ячейкой ноутбука.

## Модель

- Фото кодирует `efficientnet_b3` (timm) на картинках 300x300.
- Ингредиенты в виде текста кодирует `bert-base-uncased`.
- Эмбеддинги проецируются в размерность 256, склеиваются с массой порции и подаются в MLP-голову с одним выходом.
- Модель предсказывает калорийность на грамм, которая затем умножается на массу.
- Лосс L1, AdamW с разными lr для энкодеров и головы, CosineAnnealingLR, 30 эпох, батч 16.
- Аугментации: отражения, повороты на 90 градусов, лёгкий color jitter для фото и перемешивание порядка ингредиентов для текста.

## Анализ ошибок

Самые большие ошибки (около 300-350 ккал) модель делает на очень калорийных блюдах (орехи, пицца, салаты с маслом и сыром) и всегда их недооценивает. Причины в том, что в тексте нет граммовок ингредиентов, масло и соусы почти не видны на фото, часть снимков нетипичная (цветная посуда, обрезанный кадр), а также встречаются и несоответствия между фото и разметкой.

## Структура

```Markdown
data/               датасет (не хранится в репозитории)
scripts/
  config.py         конфиг обучения
  dataset.py        загрузка данных, датасет, аугментации
  utils.py          модель, обучение (train), валидация, фиксация сида
notebook.ipynb      EDA, обучение и анализ качества
requirements.txt
```

## Запуск

Ноутбук рассчитан на Google Colab с GPU, достаточно выполнить все ячейки по порядку. Обучение запускается так:

```python
from scripts.config import Config
from scripts.utils import train

model, history = train(Config)
```

Веса лучшей по val MAE эпохи сохраняются в `models/best_model.pt` (путь задаётся в `Config.SAVE_PATH`).
